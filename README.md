Features Implemented:

1. Authentication
- Email/Password login
- Google Sign-In
- Works on Android, iOS, Web

2. Home Screen
- Product listing from Firebase
- Search functionality
- Category filter
- Lazy-loading images

3. Product Detail Screen
- Product images
- Description, price
- Add to Cart
- Buy Now → Checkout
- Ratings

4. Cart Functionality
- Add/remove items
- Increase/decrease quantity
- Real-time sync using Firebase
- Total amount calculation

5. Wishlist (Bonus)
- Add to wishlist
- Sync across devices

6. Profile Screen
- View profile
- Edit name
- Sign-out
